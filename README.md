Clone this repository:
git clone https://github.com/souptik7-coder/Learning-JavaScript.git
Open the project in your favorite code editor (VS Code is recommended).
Explore the folders sequentially and run the examples in your browser.
Practice the code by modifying the examples and building your own programs.
